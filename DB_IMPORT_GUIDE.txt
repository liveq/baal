========================================
에러 나면?
========================================
- "column does not exist" → 테이블 스키마 불일치. 나한테 알려줘.
- "syntax error" → 파일 내용이 잘렸을 수 있음. 다시 복사해봐.
- "duplicate key" → 이미 데이터가 있는 것. 무시해도 됨.

========================================
완료 확인
========================================
아래 쿼리를 SQL Editor에 넣고 Run:

SELECT
  'weekly' as type, COUNT(*) FROM weekly_fortunes_data
UNION ALL
SELECT 'monthly', COUNT(*) FROM monthly_fortunes_data
UNION ALL
SELECT 'daily', COUNT(*) FROM daily_fortunes
UNION ALL
SELECT 'compatibility', COUNT(*) FROM compatibility_fortunes_data;

예상 결과:
- weekly: ~624 (12별자리 × 52주)
- monthly: ~144 (12 × 12)
- daily: ~1,080+ (12 × 90일)
- compatibility: ~66 (12C2 조합)
