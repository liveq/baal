2게시판 시스템 설계

2.1 게시판 공통 기능

모든 게시판 공통 기능

  • ✅ 읽기: 로그인 없이 가능
  • 🔒 쓰기: 로그인 필수 (소셜 로그인 - 이메일만 수집)
  • ✅ 댓글: 로그인 필수
  • ✅ 추천/비추: 로그인 필수
  • ✅ 꼬리표 걸기: 평판 500 이상

2.2 게시판 목록 페이지 (/board/[type])

UI 구성

📋 게시판 헤더
  • 게시판 이름 + 이모지 (예: 🤖 AI·Claude Code)
  • 필터 버튼: [인기순] [최신순] [댓글순]
  • 글쓰기 버튼 (로그인 시만 활성화)
📄 게시글 카드 (20개씩)
  • 제목
  • 작성자 닉네임 (익명404) + 평판 뱃지 (🥇 골드)
  • 작성 시간 (5분 전, 2시간 전...)
  • 통계: 👁️ 조회수, 💬 댓글, 👍 추천, 👎 비추
  • 베스트 뱃지 (조건 충족 시)
📱 무한 스크롤
  • 스크롤 하단 도달 시 자동으로 다음 20개 로드
  • Intersection Observer API 사용

데이터 흐름

// 게시판 목록 페이지 로직
1. URL에서 boardType 추출 (/board/ai → 'ai')
2. Supabase에서 board_type='ai' 게시글 20개 가져오기
   - ORDER BY: 인기순(upvotes DESC), 최신순(created_at DESC), 댓글순(comments_count DESC)
3. 화면에 카드 렌더링
4. 무한 스크롤 → 다음 20개 로드 (offset 사용)

2.3 게시글 상세 페이지 (/post/[id])

UI 구성

📰 게시글 본문
  • 제목 (큰 폰트, 볼드)
  • 작성자 정보: 닉네임, 평판 뱃지, 작성 시간
  • 본문 (마크다운 지원 - marked.js)
  • 통계: 조회수, 추천, 비추, 댓글 수
👍👎 추천/비추 버튼
  • 로그인 시만 활성화
  • 1인당 1표 (중복 방지)
  • 이미 투표한 경우 버튼 비활성화 + 색상 변경
  • 실시간 카운트 업데이트
💬 댓글 섹션
  • 댓글 목록 (작성 시간순)
  • 댓글 작성 폼 (로그인 시만 표시)
  • 대댓글 지원 (1depth만, parent_id 사용)
  • 댓글 추천/비추
📌 꼬리표 걸기 버튼
  • 평판 500 이상만 활성화
  • 클릭 시 모달: [👍 좋은 글] [👎 논란 글] [😂 웃긴 글] [🔥 명글] [🤔 생각할 거리]
  • 선택 시 user_tags 테이블에 저장

데이터 흐름

// 게시글 상세 페이지 로직
1. URL에서 postId 추출 (/post/abc123)
2. Supabase에서 해당 게시글 + 작성자 정보 가져오기
3. 조회수 +1 UPDATE
4. 댓글 목록 가져오기 (post_id 기준)
5. 사용자 투표 여부 확인 (votes 테이블)
6. 화면 렌더링

// 추천 버튼 클릭 시
1. votes 테이블에 INSERT {user_id, post_id, vote_type: 'upvote'}
2. posts 테이블 upvotes +1 UPDATE
3. users 테이블 작성자 reputation +1 UPDATE
4. 화면 업데이트

// 글쓰기 로직

2.5 바알의 저울 (법정 게시판) 특수 기능

⚖️ 특수 규칙

  • 댓글/채팅 삭제 불가: 한번 쓴 말은 영구 기록
  • 댓글/채팅 수정 불가: 증거 조작 방지
  • 실시간 채팅 모드 선택: 글 작성 시 토글

글쓰기 시 추가 옵션

⚙️ 모드 선택
[ ] 일반 댓글 모드 (기본)
[ ] 실시간 채팅 모드 (Supabase Realtime)
  • 일반 모드: comments 테이블 사용
  • 채팅 모드: court_chat 테이블 + Realtime 구독

실시간 채팅 모드

// Supabase Realtime 구독
const channel = supabase
  .channel('court-chat-' + postId)
  .on('postgres_changes', {
    event: 'INSERT',
    schema: 'public',
    table: 'court_chat',
    filter: 'post_id=eq.' + postId
  }, (payload) => {
    // 새 메시지 실시간 추가
    appendMessage(payload.new);
  })
  .subscribe();

// 메시지 전송
await supabase.from('court_chat').insert({
  post_id: postId,
  user_id: currentUserId,
  message: text
});

5Supabase DB 설계

5.1 핵심 테이블

users (회원)

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email VARCHAR(255) UNIQUE NOT NULL, -- 소셜 로그인 이메일
  oauth_provider VARCHAR(20) NOT NULL, -- 'kakao', 'naver', 'google'
  nickname VARCHAR(50) NOT NULL, -- '익명404' (랜덤 생성)
  
  -- 평판 (명예)
  reputation INTEGER DEFAULT 0,
  trust_level VARCHAR(20) DEFAULT 'bronze',
  
  -- 포인트 (현금)
  points INTEGER DEFAULT 0,
  
  -- 통계
  posts_count INTEGER DEFAULT 0,
  comments_count INTEGER DEFAULT 0,
  upvotes_received INTEGER DEFAULT 0,
  downvotes_received INTEGER DEFAULT 0,
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  INDEX idx_email (email),
  INDEX idx_reputation (reputation DESC)
);

posts (게시글)

CREATE TABLE posts (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  board_type VARCHAR(50) NOT NULL, -- 'ai', 'philosophy', 'court' 등
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  
  -- 바알의 저울 전용
  is_chat_mode BOOLEAN DEFAULT FALSE, -- true = 실시간 채팅
  
  -- 통계
  views INTEGER DEFAULT 0,
  upvotes INTEGER DEFAULT 0,
  downvotes INTEGER DEFAULT 0,
  comments_count INTEGER DEFAULT 0,
  
  -- 상태
  is_deleted BOOLEAN DEFAULT FALSE,
  is_best BOOLEAN DEFAULT FALSE,
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  INDEX idx_board_created (board_type, created_at DESC),
  INDEX idx_board_upvotes (board_type, upvotes DESC),
  INDEX idx_best (is_best, created_at DESC)
);

comments (댓글)

CREATE TABLE comments (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  parent_id UUID REFERENCES comments(id), -- 대댓글
  content TEXT NOT NULL,
  
  -- 통계
  upvotes INTEGER DEFAULT 0,
  downvotes INTEGER DEFAULT 0,
  
  -- 상태
  is_deleted BOOLEAN DEFAULT FALSE,
  can_edit BOOLEAN DEFAULT TRUE, -- 바알의 저울은 false
  can_delete BOOLEAN DEFAULT TRUE, -- 바알의 저울은 false
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  INDEX idx_post_created (post_id, created_at),
  INDEX idx_user (user_id)
);

votes (추천/비추)

CREATE TABLE votes (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  target_type VARCHAR(20) NOT NULL, -- 'post', 'comment'
  target_id UUID NOT NULL,
  vote_type VARCHAR(10) NOT NULL, -- 'upvote', 'downvote'
  
  created_at TIMESTAMP DEFAULT NOW(),
  
  CONSTRAINT unique_vote UNIQUE(user_id, target_type, target_id)
);

user_tags (꼬리표)

CREATE TABLE user_tags (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  tagged_user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  tagger_user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
  tag_type VARCHAR(20) NOT NULL, -- 'good', 'bad', 'funny', 'fire', 'think'
  
  created_at TIMESTAMP DEFAULT NOW(),
  
  CONSTRAINT unique_tag UNIQUE(tagger_user_id, post_id),
  INDEX idx_tagged_user (tagged_user_id, tag_type, created_at DESC)
);

court_chat (바알의 저울 실시간 채팅)

CREATE TABLE court_chat (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  message TEXT NOT NULL,
  
  created_at TIMESTAMP DEFAULT NOW(),
  
  INDEX idx_post_created (post_id, created_at)
);

5.2 꿀단지 테이블

honey_ads (광고 목록)

CREATE TABLE honey_ads (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  page_number INTEGER NOT NULL, -- 1, 2, 3, 4
  ad_platform VARCHAR(50) NOT NULL,
  ad_type VARCHAR(20) NOT NULL,
  title VARCHAR(200) NOT NULL,
  reward_points INTEGER NOT NULL,
  duration_seconds INTEGER,
  
  -- 4페이지 위치 정보
  location_lat DECIMAL(10, 8),
  location_lng DECIMAL(11, 8),
  location_name VARCHAR(200),
  
  tracking_url TEXT,
  is_active BOOLEAN DEFAULT TRUE,
  
  created_at TIMESTAMP DEFAULT NOW()
);

honey_activities (광고 활동 로그)

CREATE TABLE honey_activities (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  ad_id UUID REFERENCES honey_ads(id),
  activity_type VARCHAR(20) NOT NULL,
  reward_points INTEGER NOT NULL,
  
  ip_address VARCHAR(45),
  duration_seconds INTEGER,
  
  created_at TIMESTAMP DEFAULT NOW(),
  
  INDEX idx_user_date (user_id, created_at DESC),
  INDEX idx_ip_date (ip_address, created_at DESC)
);

honey_daily_limits (일일 제한)

CREATE TABLE honey_daily_limits (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id),
  ip_address VARCHAR(45),
  date DATE NOT NULL,
  
  page1_completed INTEGER DEFAULT 0,
  page2_completed INTEGER DEFAULT 0,
  page3_completed INTEGER DEFAULT 0,
  page4_completed INTEGER DEFAULT 0,
  
  total_points_today INTEGER DEFAULT 0,
  
  CONSTRAINT unique_user_date UNIQUE(user_id, date),
