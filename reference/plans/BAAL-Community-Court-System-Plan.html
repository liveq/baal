1프로젝트 개요

🎯 프로젝트 목표

BAAL은 단순한 커뮤니티가 아닌, 사용자들이 직접 규칙을 만들고 정의를 실현하는 엔터테인먼트형 자율 규제 플랫폼입니다.

핵심 가치

  • 투명성: 모든 과정이 공개되고 기록됨
  • 공정성: AI와 집단 지성을 통한 객관적 판단
  • 엔터테인먼트: 법정 드라마를 실시간으로 관전
  • 자율성: 운영자 개입 최소화, 커뮤니티가 스스로 정화

차별화 포인트

2핵심 컨셉

왜 "법정" 시스템인가?

기존 커뮤니티의 문제점:

  • 악플러를 신고해도 운영자 처리 지연
  • 불투명한 제재 기준
  • 억울한 제재에 대한 이의제기 불가
  • 커뮤니티 참여도 낮음

BAAL의 해결책:

  • 커뮤니티가 직접 판단 (AI 판사 or 배심원 투표)
  • 모든 과정 공개 (투명성)
  • 변호인 시스템 (공정성)
  • 실시간 관전으로 엔터테인먼트화 (참여도 ↑)

3주요 시스템 상세

3.1 회원 시스템 (OAuth Only)

📋 설계 원칙

개인정보 최소 수집으로 법적 책임 최소화

수집 정보

  • oauth_id: 카카오/네이버/구글 고유 ID (암호화 저장)
  • nickname: 랜덤 생성 ("익명" + 숫자)
  • 수집하지 않음: 이메일, 전화번호, 이름, 주소

법적 이점

  • 명예훼손/모욕 사건 발생 시: OAuth ID만 경찰에 제공 → 카카오/네이버에 요청 전달
  • 개인정보 유출 리스크 최소화
  • 개인정보처리방침 간소화
// 회원 데이터 구조 예시
{
  user_id: "kakao_abcd1234efgh5678",
  nickname: "익명404",
  created_at: "2025-01-15T09:30:00Z",
  reputation: 3332,
  trust_level: "gold"
}

3.2 평판(Reputation) 시스템

평판 계산

평판 = 받은 추천 - 받은 비추 + 보너스

등급 평판 범위 혜택
💩 쓰레기통 -100 이하 글쓰기 제한, 댓글만 가능
🥉 브론즈 0~500 기본 회원
🥈 실버 500~2000 이미지 첨부, 꼬리표 걸기
🥇 골드 2000~5000 추천 가중치 1.5배, 변호인 자격
💎 다이아 5000+ 게시판 글 고정, 광고 제거, 운영진 초대

평판 획득 방법

  • 게시글/댓글 추천: +1
  • 게시글/댓글 비추: -1
  • 베스트 게시글 선정: +50
  • 재판 변호인 승소: +200
  • 악의적 꼬리표 전과: -100

3.3 꼬리표(Tag) 시스템

💡 핵심 아이디어

유저의 전체 글 목록이 아닌, 다른 유저들이 큐레이션한 대표 글을 먼저 보여줌

작동 방식

  1. 유저 A가 유저 B의 글을 보고 인상 깊음
  2. 유저 A가 해당 글에 "꼬리표" 걸기 (카테고리 선택만, 텍스트 입력 불가)
  3. 유저 B 프로필에 방문하면 → 꼬리표 걸린 글들이 상단에 노출

꼬리표 카테고리

  • 👍 좋은 글
  • 👎 논란 글
  • 😂 웃긴 글
  • 🔥 명글
  • 🤔 생각할 거리

법적 안전성

  • 감정적 텍스트 없음 (명예훼손 불가)
  • 본인이 공개 게시판에 쓴 글 (사실유포죄 해당 안 됨)
  • 단순 링크 큐레이션 (의견 표현의 자유)

안전장치

  • 평판 500 이상만 꼬리표 걸기 가능
  • 원글 삭제 시 꼬리표도 자동 삭제
  • 악의적 꼬리표 신고 가능 (법정 재판으로)

3.4 커뮤니티 법정 시스템 ⭐

🎬 역전재판 컨셉

억울한 제재를 받은 유저가 공개 재판을 통해 무죄를 입증하는 엔터테인먼트형 분쟁 해결 시스템

재판 프로세스

단계 소요 시간 설명
1. 이의신청 즉시 억울한 꼬리표/제재에 대해 재판 요청
2. 판결 방식 선택 즉시 AI 판사 or 배심원 투표 선택
3. 변호인 모집 24시간 평판 2000+ 유저에게 변호 요청
4. 공개 재판 6~48시간 변론, 증인 소환, 실시간 관전
5. 판결 즉시 AI 또는 배심원 투표 결과 발표

판결 방식 비교

구분 AI 판사 배심원 투표
소요 시간 6시간 48시간
신청 비용 평판 -100 무료
승소 보상 평판 +50 평판 +200
변호인 불필요 선택 가능
관전 불가능 실시간 LIVE
객관성 높음 (AI 논리) 중간 (집단 지성)

AI 판사 판결 예시

⚖️ 판결문

사건번호: #142
원고: 익명404
피고: 익명666
쟁점: "MBTI 믿는년들" 글에 대한 👎 꼬리표

【판결 결과】 원고 일부 승소

【판결 이유】
1. '년들'은 성별 비하 표현으로 인정
2. 그러나 MBTI 비판 자체는 의견 표현의 자유에 해당
3. 전후 맥락상 악의적 의도는 없었으나 표현이 부적절함

【처분】
- 기존 👎 꼬리표 → 😤 '논란 발언'으로 변경
- 피고에게 경고 1회 부과
- 원고에게 🛡️ "부분 무죄" 뱃지 수여

배심원 투표 시스템

  • 투표 자격: 평판 500 이상
  • 투표 가중치:
    • 평판 500~2000: 1표
    • 평판 2000~5000: 2표
    • 평판 5000+: 3표
  • 판결 기준:
    • 찬성(꼬리표 정당) 60% 이상: 원고 패소
    • 반대(꼬리표 부당) 60% 이상: 원고 승소
    • 50~60%: 보류 (논란 표시)

3.5 변호인 시스템

변호인 자격

  • 평판 2000 이상 (🥇 골드 등급)
  • 재판 3회 이상 참여 경험
  • 악의적 꼬리표 전과 없음

변호인 인센티브

  • 승소 시: 평판 +200
  • 패소 시: 평판 -50
  • 관전자 많을수록 명성 ↑
  • 전적이 프로필에 표시 (예: 23승 7패, 승률 76%)

변호인 칭호

칭호 조건
💼 신참 변호사 승소 5회
💼 베테랑 변호사 승소 20회
💼 전설의 변호사 승소 50회 + 승률 70% 이상

3.6 실시간 관전 시스템 (팝콘 모드)

🍿 핵심 아이디어

재판을 드라마처럼 실시간으로 관전하며 채팅/응원하는 엔터테인먼트 기능

관전 기능

  • 실시간 채팅: 익명 채팅 (30자 제한, 욕설 필터링)
  • 팝콘 투척: 🍿 무료, 무제한 (리액션 표현)
  • 불꽃 보내기: 🔥 평판 10 소모 (변호인 응원)
  • 다이아 후원: 💎 평판 100 소모 (변호인 직접 후원)
  • 결과 예측 베팅: 평판 걸고 승부 예측 (판결에 영향 없음)

하이라이트 클립

재판 중 명장면을 관전자 투표로 선정 → 재판 종료 후 자동으로 하이라이트 영상 생성

관전자 수에 따른 효과

  • 관전자 100명 이상: 변호인에게 "인기 재판" 뱃지
  • 관전자 500명 이상: "화제의 재판" 메인 페이지 노출
  • 관전자 1000명 이상: "전설의 재판" 명예의 전당 등재

5데이터베이스 설계 (Supabase)

⚠️ 중요 원칙

핵심 공유 테이블(users, posts, comments)은 모든 기능이 공유하므로 절대 구조 변경 금지

새 기능 추가 시 독립 테이블로 확장 (예: news_items, test_results)

5.1 핵심 공유 테이블

users (회원)

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  oauth_provider VARCHAR(20) NOT NULL, -- 'kakao', 'naver', 'google'
  oauth_id VARCHAR(255) NOT NULL UNIQUE, -- 암호화된 OAuth ID
  nickname VARCHAR(50) NOT NULL, -- '익명404'
  reputation INTEGER DEFAULT 0, -- 평판 점수
  trust_level VARCHAR(20) DEFAULT 'bronze', -- 'bronze', 'silver', 'gold', 'diamond'
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  is_banned BOOLEAN DEFAULT FALSE,
  ban_reason TEXT,
  
  -- 통계
  posts_count INTEGER DEFAULT 0,
  comments_count INTEGER DEFAULT 0,
  upvotes_received INTEGER DEFAULT 0,
  downvotes_received INTEGER DEFAULT 0,
  
  CONSTRAINT oauth_unique UNIQUE(oauth_provider, oauth_id)
);

posts (게시글)

CREATE TABLE posts (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  board_type VARCHAR(50) NOT NULL, -- 'ai', 'philosophy', 'occult', 'humor', 'it', 'hardware'
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  -- 통계
  views INTEGER DEFAULT 0,
  upvotes INTEGER DEFAULT 0,
  downvotes INTEGER DEFAULT 0,
  comments_count INTEGER DEFAULT 0,
  
  -- 상태
  is_deleted BOOLEAN DEFAULT FALSE,
  is_best BOOLEAN DEFAULT FALSE,
  
  -- 인덱스
  INDEX idx_board_type (board_type),
  INDEX idx_created_at (created_at DESC),
  INDEX idx_best (is_best, created_at DESC)
);

comments (댓글)

CREATE TABLE comments (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  parent_id UUID REFERENCES comments(id), -- 대댓글
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  -- 통계
  upvotes INTEGER DEFAULT 0,
  downvotes INTEGER DEFAULT 0,
  
  -- 상태
  is_deleted BOOLEAN DEFAULT FALSE,
  
  -- 인덱스
  INDEX idx_post_id (post_id, created_at),
  INDEX idx_user_id (user_id)
);

5.2 추천/비추 시스템

votes (추천/비추)

CREATE TABLE votes (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  target_type VARCHAR(20) NOT NULL, -- 'post', 'comment'
  target_id UUID NOT NULL, -- post_id or comment_id
  vote_type VARCHAR(10) NOT NULL, -- 'upvote', 'downvote'
  created_at TIMESTAMP DEFAULT NOW(),
  
  CONSTRAINT unique_vote UNIQUE(user_id, target_type, target_id)
);

5.3 꼬리표 시스템

user_tags (꼬리표)

CREATE TABLE user_tags (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  tagged_user_id UUID REFERENCES users(id) ON DELETE CASCADE, -- 꼬리표 달린 유저
  tagger_user_id UUID REFERENCES users(id) ON DELETE CASCADE, -- 꼬리표 건 유저
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE, -- 꼬리표 대상 글
  tag_type VARCHAR(20) NOT NULL, -- 'good', 'bad', 'funny', 'fire', 'think'
  created_at TIMESTAMP DEFAULT NOW(),
  
  -- 제약조건
  CONSTRAINT unique_tag UNIQUE(tagger_user_id, post_id),
  
  -- 인덱스
  INDEX idx_tagged_user (tagged_user_id, tag_type, created_at DESC)
);

5.4 커뮤니티 법정 시스템

court_cases (재판 사건)

CREATE TABLE court_cases (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  case_number INTEGER UNIQUE NOT NULL, -- #142
  plaintiff_id UUID REFERENCES users(id), -- 원고
  defendant_id UUID REFERENCES users(id), -- 피고
  disputed_tag_id UUID REFERENCES user_tags(id), -- 분쟁 대상 꼬리표
  
  -- 재판 정보
  judgment_type VARCHAR(20) NOT NULL, -- 'ai_judge', 'jury'
  status VARCHAR(20) DEFAULT 'recruiting', -- 'recruiting', 'ongoing', 'finished'
  
  -- 시간
  created_at TIMESTAMP DEFAULT NOW(),
  trial_start_at TIMESTAMP,
  trial_end_at TIMESTAMP,
  
  -- 변론
  plaintiff_argument TEXT,
  defendant_argument TEXT,
  
  -- 판결
  verdict VARCHAR(20), -- 'plaintiff_win', 'defendant_win', 'partial'
  verdict_reason TEXT,
  
  -- 통계
  viewers_count INTEGER DEFAULT 0,
  max_viewers INTEGER DEFAULT 0,
  
  -- 인덱스
  INDEX idx_status (status, created_at DESC),
  INDEX idx_case_number (case_number DESC)
);

court_lawyers (변호인)

CREATE TABLE court_lawyers (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  case_id UUID REFERENCES court_cases(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  side VARCHAR(20) NOT NULL, -- 'plaintiff', 'defendant'
  applied_at TIMESTAMP DEFAULT NOW(),
  is_accepted BOOLEAN DEFAULT FALSE,
  
  CONSTRAINT unique_lawyer UNIQUE(case_id, user_id)
);

court_votes (배심원 투표)

CREATE TABLE court_votes (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  case_id UUID REFERENCES court_cases(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  vote VARCHAR(20) NOT NULL, -- 'plaintiff', 'defendant'
  weight INTEGER DEFAULT 1, -- 평판에 따른 가중치
  created_at TIMESTAMP DEFAULT NOW(),
  
  CONSTRAINT unique_court_vote UNIQUE(case_id, user_id)
);

court_chat (법정 채팅)

CREATE TABLE court_chat (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  case_id UUID REFERENCES court_cases(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  message TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  
  INDEX idx_case_chat (case_id, created_at)
);

court_reactions (팝콘/불꽃/다이아)

CREATE TABLE court_reactions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  case_id UUID REFERENCES court_cases(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id),
  reaction_type VARCHAR(20) NOT NULL, -- 'popcorn', 'fire', 'diamond'
  target_user_id UUID REFERENCES users(id), -- 변호인에게 보낸 경우
  created_at TIMESTAMP DEFAULT NOW()
);
