2. 핵심 문제점

준비중 페이지 6개 — barcode, ocr, upscale, convert, bg, chart. 원본 코드가 다 있는데 활용 안 함.
파일 입력 디자인 — 네이티브 <input type="file"> 그대로 사용. 원본은 커스텀 드래그앤드롭 영역.
기능 격차 — 원본 대비 핵심 기능 다수 누락 (드래그앤드롭, 배치 처리, 미리보기 비교 등).
공통 디자인 시스템 미적용 — 원본은 _common/common.css로 통일된 디자인. 재현은 개별 tailwind 클래스.

3. 해결 방향

즉시 가능 — 원본 HTML을 그대로 Next.js 컴포넌트로 변환. 로직+디자인 100% 가져오기. 원본 코드 tools_repos/에 다 있음.
파일 입력 — 커스텀 드래그앤드롭 컴포넌트 만들기. 원본의 .upload-area 스타일 참고.
공통 스타일 — 원본 _common/common.css의 CSS 변수를 tailwind config에 반영.

  • 다크모드 지원

  • 다크모드 없음
  • 광고 없음
  • SEO 없음
  • tailwind 개별 스타일

5. 결론

솔직한 평가: 원본 코드가 tools_repos/에 17개 전부 있었는데, 이걸 제대로 활용하지 않고 처음부터 새로 짠 건 비효율적이었음. 원본은 각각 600~1600줄의 완성된 코드인데, 재현은 18~143줄로 기능이 대폭 축소됨.

해야 할 일: 원본 HTML/JS 로직을 그대로 Next.js 컴포넌트로 이식하는 게 맞음. 디자인도 원본 _common/common.css 기반으로 통일.
